# Motchill — Điều khiển trình phát

Phiên bản **6.0.7**. Mở [link cài](https://raw.githubusercontent.com/nhattruong16062003/media-userscripts/v0.4.7/motchill/gestures/motchill-gestures.user.js) bằng Firefox đã cài Tampermonkey, rồi chọn Cài đặt/Cập nhật.

Xem [hướng dẫn sử dụng](../README.md). Giữ script hiện có khi cập nhật để giữ dữ liệu.

Nguồn Next tương thích như motchilll.vip dùng giao diện gốc kèm cử chỉ, khóa, bỏ giới thiệu và chuyển tập. Các nút trùng được ẩn; không thêm thanh phát/dừng, chất lượng hoặc âm lượng thứ hai. Những nguồn đã hỗ trợ chế độ custom tiếp tục dùng giao diện custom.

Tải lại cùng website sẽ nhớ lựa chọn bật/tắt tiếng. Phim đang chạy chỉ được thử khôi phục âm thanh; nếu trình duyệt không cho bật tiếng thì bỏ qua, không pause hoặc bắt bấm Play lại.
