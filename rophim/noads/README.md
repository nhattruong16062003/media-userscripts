# RoPhim — Chặn quảng cáo

Phiên bản **0.4.25**. Mở [link cài](https://raw.githubusercontent.com/nhattruong16062003/media-userscripts/v0.4.25/rophim/noads/rophim-noads.user.js) bằng Firefox đã cài Tampermonkey, rồi chọn Cài đặt/Cập nhật.

Xem [hướng dẫn sử dụng](../README.md) và [cài trên Firefox](../docs/FIREFOX.md).

Chặn popup do mã trang tự mở, kể cả quảng cáo chưa được nhận diện. Bấm liên kết ra ngoài website sẽ được hỏi trước; liên kết ứng dụng không được hỗ trợ bị chặn. Link phim cùng website vẫn hoạt động. Iframe phim được hỗ trợ bị hạn chế mở popup/chuyển trang cha. Cập nhật rồi tải lại trang.

Userscript không chặn tuyệt đối mọi cách chuyển trang/app: trên Firefox, mã trong trang cha tự đổi địa chỉ hoặc chuyển hướng từ máy chủ vẫn có thể nằm ngoài khả năng chặn.
